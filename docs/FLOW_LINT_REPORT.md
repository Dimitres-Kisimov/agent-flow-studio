# Flow lint report

Generated by `node scripts/lint-flows.js --write` from the flows in the folders below.
It is a pure, deterministic function of those files — re-running reproduces it byte-for-byte,
so it can be committed and diffed. The example flows are illustrative, not exhaustive.

The linter reports **structural / wiring** problems that are decidable from the graph and the
node specs alone (see the rule table at the end). It does not prove a flow is correct, reason
about payload contents, or follow the data-dependent branch a Condition takes at run time.

## Rules

| Code | Severity | What it means |
| --- | --- | --- |
| `CYCLE` | error | Flow contains a cycle (must be acyclic). |
| `DEAD_END` | warning | Node output is not wired anywhere — its work is discarded. |
| `DUPLICATE_EDGE_ID` | warning | Two edges share an id. |
| `DUPLICATE_NODE_ID` | error | Two nodes share an id. |
| `EDGES_NOT_ARRAY` | error | Flow.edges is not an array. |
| `EDGE_DANGLING_SOURCE` | error | Edge starts at a node that does not exist. |
| `EDGE_DANGLING_TARGET` | error | Edge ends at a node that does not exist. |
| `EDGE_MALFORMED` | error | Edge is missing a from/to endpoint. |
| `EDGE_MISSING_ID` | warning | An edge is missing an id. |
| `EMPTY_FLOW` | warning | Flow has no nodes. |
| `EMPTY_TOOLBELT` | warning | Agent has no tools — it can only respond directly. |
| `FLOW_NOT_OBJECT` | error | Flow is not an object. |
| `INVALID_SOURCE_PORT` | error | Edge leaves an output port the node does not have. |
| `INVALID_TARGET_PORT` | error | Edge enters an input port the node does not have. |
| `NODES_NOT_ARRAY` | error | Flow.nodes is not an array. |
| `NODE_MISSING_ID` | error | A node is missing an id. |
| `NO_OUTPUT` | warning | Flow has no Output — no result is captured. |
| `NO_TRIGGER` | error | Flow has no Trigger — nothing can start it. |
| `SELF_LOOP` | error | Edge connects a node to itself. |
| `UNKNOWN_AGENT_TOOL` | warning | Agent lists a tool the engine does not provide. |
| `UNKNOWN_NODE_TYPE` | error | Node has a type the engine does not know. |
| `UNKNOWN_TOOL` | error | Tool node names a tool the engine does not provide. |
| `UNREACHABLE_NODE` | warning | Node is not reachable from any Trigger. |
| `UNSATISFIED_INPUT` | error | Node has no incoming edge to feed its input. |
