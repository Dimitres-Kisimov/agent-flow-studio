How it works

  1. Drag nodes onto the canvas.
  2. Drag from an output port (right) to an input port (left) to wire them.
  3. Click a node to edit its config.
  4. Press Run to execute and watch the trace.
  5. Press Lint to check for structural problems before running.
  6. Type a Test input next to Run for a one-off what-if payload.
  7. Select a node/wire and press Delete to remove it.
  8. Ctrl+Z / Ctrl+Y undo and redo any edit.
  9. Snapshot downloads a PNG or SVG picture of the canvas.
